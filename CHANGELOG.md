# Changelog

## 0.1.0

- First release: Format Document and Format Selection for HTML, CSS, SCSS and LESS with the bundled js-beautify 1.15.4, .editorconfig support, keep-as-written defaults (pre, textarea, inline tags, attribute order, blank lines, SCSS maps, trailing comments) and an opt-in format on save.
- Pro tools, 3 free tries each: format a folder with a diff preview, minify HTML and CSS with a size report, and an HTML lint report.
